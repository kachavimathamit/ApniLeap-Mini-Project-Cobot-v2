 NOTES
==============================================================================
  * Hierarchy: institutes -> departments -> projects. There is no schools table any more.
  * departments.id is an integer (sequence departments_id_seq); departments.code is generated by
    trigger trg_department_code as Dept-<id> when not supplied (never typed by users).
  * A Dean / Department Head sees only the departments in user_department_access (a college-wide
    grant in user_institute_access only says which college they belong to).
  * Team ID (Team-n) and Artefact ID (Art-n) on projects come from sequences team_id_seq / artefact_id_seq.
  * project_students holds 4 or 5 students per project (slot 1-5); no mobile number is stored.
    project_students.email is a generated column: lower(srn) || '@kletech.ac.in'.
  * users.srn is set only for student accounts (login = SRN, created from project teams).
  * uq_project_students_srn (one SRN, one team) is added by db:init once no SRN is repeated in old data.
  * projects.start_date / expected_completion_date are no longer used by the application.
  * updated_at is maintained by trigger trg_set_updated_at on the main tables.
